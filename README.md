## 공식 주제

지역 중소기업의 안전한 생성형 AI 활용을 위한 민감정보 유출 차단 게이트웨이

## 한 줄 설명

직원이 생성형 AI에 입력하는 프롬프트와 문서를 외부 전송 전에 검사하고, 민감도에 따라 마스킹·내부 LLM 처리·전송 차단을 제안하는 보안 게이트웨이

## 문제

직원이 개인정보·거래처·제품 단가·내부 코드 등을 생성형 AI에 입력하면 외부 서비스로 전달될 위험이 있다. 기업용 보안 솔루션은 존재하지만 지역 중소기업에는 비용과 운영 복잡성이 부담이 될 수 있다.

## 제안 방향

| 등급 | 제안 처리 방식 |
|---|---|
| 일반 | 외부 또는 내부 LLM 사용 |
| 주의 | 민감정보 마스킹 후 전달 |
| 기밀 | Ollama 내부 LLM 처리 |
| 위험 | 전송 차단 또는 관리자 승인 |

## 시스템 처리 흐름

```
직원이 질문 또는 문서 입력
        │
        ▼
Nginx를 거쳐 FastAPI 게이트웨이
        │
        ▼
    민감정보 탐지
        │
        ▼
  보안정책으로 등급 결정
        │
   ┌────┼────┬────┐
   ▼    ▼    ▼    ▼
  위험  일반  주의  기밀
   │    │    │    │
차단/  외부/  마스킹 Ollama
승인   내부   후전달  내부LLM
       LLM
   │    │    │    │
   └────┴────┴────┘
        │
        ▼
    감사 로그 기록
        │
        ▼
   사용자에게 결과 표시
```

## 제안 기술 구성

아래 기술은 기획서의 구현 후보이며 현재 구현 완료를 의미하지 않는다.

| 구분 | 제안 기술 |
|---|---|
| 화면 | React |
| 게이트웨이 | Nginx |
| 백엔드 | Python, FastAPI |
| 민감정보 탐지 | 정규식, 기업 사전, 한국어 NER, 문맥 분류 |
| 내부 LLM | Ollama 기반 로컬 오픈소스 모델 (모델명 미정) |
| 데이터베이스 | PostgreSQL |
| 향후 실행 환경 | Docker Compose |

## 폴더 구조

```
.
├── frontend/   # React 화면
├── backend/    # FastAPI 백엔드, 민감정보 탐지, 내부 LLM 연동
├── gateway/    # Nginx 설정
└── docs/       # 기획·조사·설계 문서
```
