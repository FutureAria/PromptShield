# 근거 자료

기획서에 쓴 주장의 출처. 전 항목 원문 URL 또는 발간 정보를 확인했다.
확인하지 못한 것은 기획서에 쓰지 않았다.

## 문제 정의

**대한상공회의소 경제연구원, 임금근로자 3,000명 조사, 2026.6**
중소기업 근로자의 **52.7%**가 생성형 AI를 업무에 활용하지만, 사내 가이드라인을 받은
비율은 **24.3%**에 그쳤다.
→ 기획서 1쪽 "절반 이상이 지침 없이 이미 쓰고 있다"의 근거.
※ 주어는 '중소기업'이 아니라 **'중소기업 근로자'**다. 인용 시 주의한다.

**과학기술정보통신부·한국정보보호산업협회, 「2025년 정보보호 실태조사」**
국가승인통계 제342005호. 2024년 기준, 종사자 10인 이상 사업체 5,500개사.
정보보호 예산 사용률 54.8%, 정보보호 교육 실시율 32.7%,
정보보호 업무 수행 기업(79.9%) 중 정보보호 조직 보유율 35.3%.
https://www.korea.kr/briefing/pressReleaseView.do?newsId=156751368
→ "전담 인력이 없다"는 서술의 근거.

**대구상공회의소, 「정보보호 대응 실태 및 애로조사」, 2025**
대구 지역 263개사 응답.
→ 지역 중소기업의 정보보호 부담.

**LayerX, 『Enterprise AI and SaaS Data Security Report 2025』, 2025.10**
생성형 AI에 붙여넣는 행위의 **82%가 회사가 관리하지 않는 계정**을 경유.
https://go.layerxsecurity.com/hubfs/LayerX_Enterprise_AI_and_SaaS_Data_Security_Report.pdf
※ 확률표본 조사가 아니라 해당 업체 고객사의 브라우저 텔레메트리 기준이다.
→ "기업 계약을 맺어도 개인 계정 사용은 막지 못한다"의 근거.

**Samsung / ChatGPT 사례, 2023**
Laura Dobberstein, 「Samsung reportedly leaked its own secrets through ChatGPT」,
The Register, 2023.4.6. https://www.theregister.com/2023/04/06/samsung_reportedly_leaked_its_own/
(원 보도: 정두용, 이코노미스트, 2023.3.30)
사용 허용 20일 만에 소스코드·회의록 입력 사례가 보고됐다.

## 설계 판단의 근거

**B. Stanton, M. F. Theofanos, S. S. Prettyman, S. Furman, 「Security Fatigue」**
『IT Professional』 18(5), pp.26-32, 2016. DOI 10.1109/MITP.2016.84
NIST 연구진, N=40 반구조화 인터뷰. 보안 판단 요구가 누적되면 체념과 결정 회피가 나타난다.
→ 일반 등급은 무개입, 주의 등급부터 화면에 표시하는 설계의 근거.

**Ollama, 「FAQ — How does Ollama handle concurrent requests?」**
https://docs.ollama.com/faq
메모리 소요는 동시 실행 수와 컨텍스트 길이에 비례한다.
→ 시연 장비를 소형 모델·낮은 동시성·컨텍스트 상한으로 고정한 근거.
